| Платформа | Файл | Примечание |
|:---|:---|:---|
| **Windows** | [`.exe` (NSIS Installer)](../../releases) | Требует Windows 10/11 x64 |
| **macOS** | [`.dmg` Installer](../../releases) | Требует macOS 12+ (Apple Silicon & Intel) |

> 📦 Все релизы доступны на странице [Releases](../../releases).  
> ⏱️ Артефакты сборки автоматически обновляются при пуше в ветку `pc_version`.

### Безопасность при первом запуске

#### Windows (SmartScreen)
При первом запуске может появиться предупреждение *"Windows защитила ваш компьютер"*.  
✅ Решение: нажмите `Подробнее` → `Выполнить в любом случае`.  
*(Приложение не содержит вредоносного кода. Блокировка связана с отсутствием платной код-подписи.)*

#### macOS (Gatekeeper)
macOS может заблокировать запуск с сообщением *"Приложение повреждено"* или *"От неопознанного разработчика"*.  
✅ Решение:
1. Откройте **Терминал** и выполните:
   ```bash
   xattr -cr /Applications/НазваниеПриложения.app
   ```
2. Либо: `ПКМ по приложению → Открыть → подтвердить в диалоге`.
*(Это стандартное поведение macOS для неподписанных приложений.)*

## Запуск из исходников (для разработчиков)

### Требования
- Node.js `v20+`
- Rust `stable`
- [Tauri CLI](https://tauri.app/v1/guides/getting-started/prerequisites)

### Установка зависимостей
```bash
npm install --legacy-peer-deps
```

### Запуск в режиме разработки
```bash
npm run tauri dev
```

### Сборка локально
```bash
npm run tauri build
# Готовые бинарники появятся в src-tauri/target/release/bundle/
```

##  Автоматическая сборка
Сборка настроена через GitHub Actions. При каждом пуше в ветку `pc_version` или ручном запуске workflow:
1. Собирается актуальная версия под Windows (`.exe`) и macOS (`.dmg`)
2. Файлы автоматически публикуются в разделе **Releases**
3. Кэшируются зависимости Node.js и Rust для ускорения последующих сборок
